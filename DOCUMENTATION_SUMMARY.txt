KEY FEATURES DOCUMENTED

CONNECTION SYSTEM
- Doctor-Patient: bidirectional acceptance
- Family-Patient: support relationship
- Permission Levels: NOT_ALLOWED, REQUEST, SELECTED, ALLOWED
- Audit logged for all changes

PRESCRIPTION MANAGEMENT
- Lifecycle: DRAFT → ACTIVE → PAUSED → INACTIVE
- Versioning: all changes create new version
- History: complete change tracking
- Urgent Updates: auto-apply with notification

DOSE TRACKING (OFFLINE-FIRST)
- Online: immediate backend updates
- Offline: local storage with sync when online
- Status: DUE, TAKEN_ON_TIME, TAKEN_LATE, MISSED, SKIPPED
- Escalation: missed alerts → family notification

HEALTH MONITORING
- Vital Signs: BP, HR, Glucose, Temperature, Weight, SpO2
- Thresholds: customizable per patient
- Alerts: automatic when threshold exceeded
- Doctor Notifications: connected physicians alerted

AUDIT LOGGING
- Every action logged
- Immutable audit trail
- User transparency
- Compliance ready

SUBSCRIPTIONS
- FREEMIUM: Free, 5GB, 1 member
- PREMIUM: $0.50/mo, 20GB, all features
